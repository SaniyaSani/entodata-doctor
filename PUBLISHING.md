# Как опубликовать EntoData Doctor

EntoData Doctor — статическое браузерное приложение. Для него не нужны
Streamlit, Python, база данных, API-ключ или платный сервер. Самый простой
вариант — GitHub Pages.

## Первая публикация

1. Распакуйте ZIP-архив.
2. На GitHub создайте новый **public repository**, например
   `entodata-doctor`.
3. В репозитории нажмите **Add file → Upload files**.
4. Загрузите **содержимое распакованной папки**, включая `index.html`,
   `entodata-doctor.js`, `entodata-doctor.css` и папку `vendor`.
5. Нажмите **Commit changes**.
6. Откройте **Settings → Pages**.
7. В разделе **Build and deployment** выберите **Deploy from a branch**.
8. Выберите ветку `main`, папку `/ (root)` и нажмите **Save**.

Через несколько минут GitHub покажет публичный адрес приложения. Таблицы
пользователей всё равно обрабатываются в их браузере и не отправляются на
GitHub.

## Как опубликовать следующую версию

Замените файлы в том же репозитории файлами из нового ZIP-архива и сделайте
новый commit. GitHub Pages обновит приложение автоматически.
